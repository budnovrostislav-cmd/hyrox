# Трекер HYROX

Личное веб-приложение для подготовки к HYROX Open Men: план дня, тренировки с таймером отдыха, питание, бег и станции HYROX, графики.

## Установка на iPhone

1. Загрузи все файлы этой папки в репозиторий GitHub и включи GitHub Pages (Settings → Pages → Deploy from a branch → main, / (root)).
2. Открой адрес сайта в Safari на iPhone.
3. «Поделиться» → «На экран „Домой“» → «Добавить».
4. Запускай с иконки: приложение откроется на весь экран и будет работать без интернета.

## Данные

Данные хранятся только на iPhone, внутри установленного приложения. Раз в неделю делай резервную копию: настройки → «Экспорт JSON». Восстановление — «Импорт JSON».

## Обновление

Замени файлы в репозитории новыми. Приложение подтянет обновление при следующем запуске с интернетом. Данные при этом не теряются.
